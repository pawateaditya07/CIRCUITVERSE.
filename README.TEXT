MINI 3D DRIVER — HOW TO RUN

REQUIREMENTS
- VS Code
- A modern browser (Chrome, Edge, Firefox)
- Internet connection to load Three.js from jsDelivr CDN

FILES
- index.html
- style.css
- game.js

RUN ON YOUR COMPUTER
1. Extract this folder.
2. Open VS Code.
3. Choose File > Open Folder, then select mini_3d_driving_game.
4. In VS Code, install the "Live Server" extension by Ritwick Dey (if available).
5. Right-click index.html and choose "Open with Live Server".
6. Click START DRIVING.
7. Use Left/Right arrows or A/D to steer. Up/W accelerates. Down/S brakes. Space pauses.

NO LIVE SERVER?
Use a terminal in this folder and run:
  python -m http.server 8000
Then open:
  http://localhost:8000

MOBILE
- To test on a phone, the phone and computer should be on the same Wi-Fi.
- Start the local server on the computer and find the computer's local IP address.
- Open http://YOUR-COMPUTER-IP:8000 on the phone.
- If your firewall blocks access, allow the local connection.
- You can also host the files on a static hosting service, then open its HTTPS URL on your phone.

NOTES
- This is a beginner 3D arcade prototype, not a full simulation.
- Three.js is loaded from the internet, so the game needs a connection unless you download and configure the library locally.
